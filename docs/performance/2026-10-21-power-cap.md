## 本机默认200W

系统服务 `ninfer-gpu-power-limit.service`，UUID定位，`/etc/default/ninfer-gpu-power-limit` 配置200W/原默认300W。启用 persistence 并设置上限，开机自动应用；失败重试。实际本机安装和当前限额核对另存service-receipt.json，未重启电脑验收。

```sh
sudo systemctl enable --now ninfer-gpu-power-limit.service
systemctl status ninfer-gpu-power-limit.service
nvidia-smi --query-gpu=uuid,power.limit --format=csv
# 撤销自启并恢复300W（ExecStop）：
sudo systemctl disable --now ninfer-gpu-power-limit.service
```

NVIDIA接口依据：[nvidia-smi官方说明](https://docs.nvidia.com/deploy/nvidia-smi/index.html)。源unit位于 `tools/systemd/ninfer-gpu-power-limit.service`，必须连同本机UUID配置安装。
